# Гайды по Испании

Практические гайды на русском языке о жизни, переезде и путешествиях по Испании.

## Структура

```
guides/          готовые гайды: файл на тему или папка для многостраничного гайда
templates/       шаблон для нового гайда
src/             код сайта на Astro + Starlight
  markdown/      разметка гайдов (плашки документов, сумм, сроков)
  styles/        оформление этой разметки
  scripts/       чек-листы с отметками, кнопка «Скопировать», калькулятор дат
```

## Как добавить гайд

1. Скопируйте `templates/guide.md` в `guides/<тема>.md`. Имя файла пишите латиницей через дефис, например `guides/nie.md` или `guides/arenda-zhilya.md`.
2. Заполните `title` и `description` в начале файла и разделы шаблона. Заголовок `# ...` в тексте не нужен: сайт берёт его из `title`.
3. Укажите источники и дату последней проверки: правила и цены в Испании часто меняются.

### Многостраничный гайд

Длинный гайд из нескольких шагов кладите в папку `guides/<тема>/`:

- `index.md` — обзор. Его `title` становится названием группы в меню.
- Остальные страницы — по одной на шаг, например `shag-1-poezdka.md`.
- Порядок в меню и кнопки «Предыдущая / Следующая» задаёт `sidebar.order`, короткое название в меню — `sidebar.label`.
- `step: 3` — над заголовком появится «Шаг 3 из N» и полоска для перехода между шагами.
- `who: host | guest | both` — кто делает шаг: приглашающий, гость или оба. Влияет на цвет шага в полоске.

Ссылки между страницами одного гайда пишите относительными: `../shag-2-padron/`.

## Разметка гайдов

Кроме обычного Markdown, в гайдах можно выделять типы данных. Каждый тип выглядит по-своему, поэтому документы, суммы и сроки видно с первого взгляда.

**В строке**

| Пишем | Что это |
| --- | --- |
| `:doc[Carta de invitación]` | документ |
| `:fee[75,05 €]` | сумма |
| `:time[9 месяцев]` | срок |
| `:place[C/ Rosal, 23, Oviedo]` | место, адрес |
| `:host[]`, `:guest[]`, `:sponsor[]` | кто делает: приглашающий, гость, спонсор |
| `:fill[ФИО гостя]` | поле, которое нужно заполнить (в шаблонах) |

**Блоки**

```
:::summary
- **Кто делает:** :host[]
- **Сколько стоит:** :fee[6,54 €]
:::

:::doc[Certificado de empadronamiento]{who="host" where="Ayuntamiento" form="Оригинал" fresh="1 месяц" when="до подачи"}
Текст о документе.
:::

:::checklist[Название списка]{who="guest" id="unikalnyj-id"}
- [ ] Пункт
:::

:::template[Название шаблона]
Текст, который можно скопировать кнопкой. :fill[Поле]
:::

:::steps
1. **Шаг**

   Описание.
:::
```

- `summary` — карточка «Коротко» в начале шага.
- `doc` — карточка документа. Все атрибуты необязательны. С `kind="place"` — карточка организации или офиса (значок места), адрес — в атрибуте `place`.
- `checklist` — список с галочками и прогрессом. Отметки сохраняются в браузере читателя. Обычные списки `- [ ]` тоже становятся кликабельными.
- `template` — текст с кнопкой «Скопировать»: письма, сообщения, справки.
- `steps` — нумерованная лента шагов.
- `::planner` — калькулятор дат для визы по приглашению (`src/scripts/visa-planner.ts`). Его допущения совпадают с таблицей на странице «Календарь и сроки»: меняете одно — меняйте и другое.
- `::tariffs{kind="luz"}` и `::tariffs{kind="gas"}` — сравнение двух тарифов на свет или газ за год (`src/scripts/tariff-calc.ts`). В газовом калькуляторе зашиты цены TUR: их пересматривают раз в квартал (1 января, апреля, июля, октября). При обновлении поменяйте `TUR` и `TUR_SOURCE` в скрипте и таблицу TUR в `guides/kommunalnye-uslugi/gaz.md`.

Как это устроено: `src/markdown/guide-directives.mjs`, оформление — `src/styles/guide.css`.

## Сайт

Гайды публикуются как сайт на [Astro](https://astro.build) с темой [Starlight](https://starlight.astro.build): https://kavaivaleri.github.io/spain-guides/

Каждый файл `guides/<slug>.md` становится страницей `/<slug>/`, а `guides/<slug>/<page>.md` — страницей `/<slug>/<page>/`. Главная страница и меню слева собираются автоматически.

Локальный запуск (нужен Node.js 22+):

```
npm install
npm run dev      # http://localhost:4321/spain-guides/
npm run build    # сборка в dist/
```

После каждого пуша в `main` GitHub Actions собирает сайт и публикует его на GitHub Pages (`.github/workflows/deploy.yml`).
